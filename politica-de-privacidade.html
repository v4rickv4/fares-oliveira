Política de Privacidade — Fares Ads Dashboard

Última atualização: 19 de setembro de 2026

A presente Política de Privacidade descreve com clareza e transparência como o Fares Ads Dashboard, gerido pela Fares Araújo & Associados, coleta, utiliza, processa e protege os dados quando você acessa a aplicação ou autoriza o acesso às suas contas publicitárias do Google.

O Fares Ads Dashboard é uma aplicação de uso interno e acesso restrito, desenvolvida especificamente para viabilizar consultas e análises consolidadas de desempenho para equipes autorizadas.

Dados do Google acessados

O Fares Ads Dashboard acessa dados de contas Google Ads autorizadas pelo usuário através do OAuth 2.0 e da Google Ads API.

Dependendo das permissões da conta, esses dados podem incluir identificação da conta Google Ads, campanhas, grupos de anúncios, anúncios, palavras-chave e métricas de desempenho como impressões, cliques, custos e conversões.

A aplicação realiza operações exclusivamente de leitura e consulta. Em nenhuma circunstância o Fares Ads Dashboard realiza criação, edição ou exclusão de campanhas publicitárias.

Como utilizamos os dados do Google

Os dados obtidos através da Google Ads API são utilizados exclusivamente para geração de dashboards, relatórios internos, acompanhamento de indicadores e análises de desempenho das contas publicitárias autorizadas.

O objetivo primário e único do processamento destas informações é permitir o acompanhamento estruturado dos resultados das campanhas gerenciadas, auxiliando os profissionais responsáveis na tomada de decisão operacional e estratégica.

Armazenamento e segurança

O Fares Ads Dashboard adota medidas de proteção para preservar a integridade e a privacidade dos dados coletados:

  • Tokens de Autorização OAuth: Os tokens de acesso concedidos pelo usuário durante o fluxo de autorização OAuth 2.0 são armazenados em ambiente seguro de infraestrutura em nuvem, com controle de acesso rigorosamente restrito aos serviços e pipelines internos necessários para executar as consultas de métricas da API.
  • Dados em Trânsito: Todas as comunicações entre os usuários, os sistemas do Fares Ads Dashboard e as APIs do Google são realizadas exclusivamente por canais criptografados via protocolo HTTPS (TLS).
  • Período de Retenção: Os dados de métricas e os tokens de conexão permanecem armazenados apenas enquanto houver vínculo ativo para prestação dos serviços de análise e relatórios. Caso o vínculo seja descontinuado ou a autorização seja revogada, as informações e credenciais de acesso são eliminadas.

Compartilhamento de dados

Os dados obtidos das APIs do Google não são vendidos, alugados ou utilizados para publicidade personalizada. O acesso aos dados é limitado às pessoas e aos serviços necessários para a operação do Fares Ads Dashboard.

Não transferimos ou compartilhamos informações de contas Google com quaisquer terceiros estranhos à operação da plataforma, salvo por expressa determinação judicial ou cumprimento de obrigação legal.

Google API Services User Data Policy

O uso e a transferência para qualquer outro aplicativo das informações recebidas das APIs do Google pelo Fares Ads Dashboard obedecerão à Google API Services User Data Policy, incluindo os requisitos de Limited Use (Uso Limitado).

Revogação de acesso

O usuário tem total controle sobre suas permissões e pode revogar o acesso do Fares Ads Dashboard a qualquer momento diretamente através das configurações de segurança de sua própria Conta Google.

Para gerenciar ou revogar os acessos concedidos, basta visitar a página oficial de permissões de aplicativos do Google:
https://myaccount.google.com/permissions

Assim que a autorização for revogada pelo usuário no painel do Google, o Fares Ads Dashboard perderá imediatamente a capacidade de efetuar novas requisições ou coletar atualizações de dados da respectiva conta.

Exclusão de dados

O usuário pode a qualquer momento solicitar a exclusão definitiva de quaisquer dados, identificadores ou tokens de acesso associados à sua conta armazenados nos sistemas do Fares Ads Dashboard.
